# ORCA Swimming Academy 🏊

تطبيق ويب حديث لإدارة أكاديمية السباحة ORCA - تسجيل الطلاب والجداول الزمنية والجلسات.

## المميزات ✨

- 🏊 **تسجيل الطلاب** - نموذج تسجيل سهل الاستخدام
- 📋 **إدارة الجلسات** - عرض الجلسات والتقييمات
- 📱 **متجاوب تماماً** - يعمل على جميع الأجهزة
- 🔐 **تسجيل دخول آمن** - مع التحقق من البيانات
- 🎨 **تصميم حديث** - واجهة مستخدم جميلة وفعالة

## التكنولوجيا المستخدمة 🛠️

- **React 19.1.1** - مكتبة JavaScript
- **CSS3** - أنماط متقدمة
- **PapaParse** - معالجة ملفات CSV
- **Vercel** - نشر سحابي

## التثبيت 📦

```bash
# استنساخ المشروع
git clone https://github.com/yourusername/ORCA-Academy.git
cd ORCA-Academy

# تثبيت الحزم
npm install

# تشغيل المشروع
npm start

# بناء المشروع للإنتاج
npm run build
```

## الاستخدام 🚀

### الصفحة الرئيسية
- اعرض معلومات الأكاديمية
- الصور والأنشطة
- نموذج التسجيل

### تسجيل الدخول
- أدخل الاسم ورقم الهاتف
- عرض جدول الجلسات الخاص بك

### جدول الجلسات
- عرض معلومات الطالب
- قائمة الجلسات والتقييمات
- حالة كل جلسة ✅/❌
